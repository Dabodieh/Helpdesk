Graphite Helpdesk — Independent static visual concept

Open index.html after extracting the ZIP.

The four working example screens are linked from the index. Theme switching,
Department filtering, mailbox add/edit preview and ticket selection/note mode
are functional locally, without touching Helpdesk's real data or application.

No external dependencies or font files. Built from Codex's original Graphite
styles.css and planning documents, with original completion work added.

Browser screenshots could not be generated in this environment because Chromium
is configured to block all URL navigation. The landing page therefore renders
live miniatures of the actual prototype screens.
