Helpdesk Visual prototype Theme

A service desk that looks like it was built to be bought.

Phase 1 visual direction for Helpdesk: one design system applied to the global shell, Administration, a Department’s setup and communication settings, and the agent Ticket Workspace. Static HTML only — nothing here is wired to the application, its APIs or its data. Sample data reuses existing Helpdesk concepts.

Prototype only. Lives under docs/design/redesign/prototype/ and is safe to delete. The command palette is a Concept preview, not an existing or committed feature. Controls marked “Not part of this prototype” are intentionally inert.

How this extends

Requester Portal
  • Same tokens and type scale; the ink rail becomes a light top bar, no left navigation.
  • Search-first home, request forms and knowledge as plain lists, status pills for “My requests”.
  • Audience rules, Internal Note exclusion and department boundaries unchanged.
Reusable components that would change
  • App shell, rail and top bar; page header and breadcrumbs.
  • Tabs → section navigation; data table; status pill and chip.
  • Field and form layout; Dialog → Drawer for create/edit.
  • Empty state, callout, switch, command palette (concept).
